# 02_data/derived

Analysis-ready tables written by `01_code/R/01_build_datasets.R`. **Do not edit by hand.** They are regenerated by `Rscript 01_code/R/run_all.R`.

## `survey_beach_year.csv`

One row per beach × survey year (1997–2025; the 2025 rows have length data but no abundance estimate yet).

| Column | Meaning |
|---|---|
| `beach`, `season`, `survey_year` | Identifiers (`survey_year` = first year of `season`) |
| `habitat_m2`, `pre_recruits`, `recruits` | From the WDFW season summary |
| `harvest_total`, `exploitation_rate`, `TAC` | Fishery statistics for the season that follows the survey |
| `survey_date_first`, `survey_date_last`, `survey_doy` | First and last measured date, and median day of year of measured clams |
| `survey_doy_imputed` | TRUE where no usable dates existed (Kalaloch 2001, Copalis 2003); filled with the beach median |
| `n_measured`, `n_dated` | Clams measured; clams with a parseable date |
| `p_pre`, `p_76_100`, `p_101_120`, `p_gt120` | Share of measured clams in each size class |
| `p_pre_lt30` | Share of measured pre-recruits < 30 mm |
| `median_length_mm` | Median shell length |
| `pre_density`, `rec_density` | Abundance / habitat area (clams m⁻²) |

## `env_monthly.csv`

One row per year × month, 1988–2026.

| Column | Meaning |
|---|---|
| `beuti_46N`, `beuti_47N`, `cuti_46N`, `cuti_47N` | Monthly means of daily indices (requires ≥20 days) |
| `q_cms` | Columbia River discharge at The Dalles, monthly mean (m³ s⁻¹) |
| `pdo` | PDO index |
| `sst_anom` | Regional SST anomaly (°C) from the two-way station homogenisation (`01_code/R/lib_env_homogenize.R`) of the open-coast stations 46029, 46041, 46211, 46099, 46100 and 46248 (months need ≥240 hourly obs; climatology 1991–2024) |
| `sst_anom_se` | Standard error of `sst_anom` (0.15–0.4 °C depending on how many stations report) |
| `n_sst_stations` | Number of stations contributing to `sst_anom` |
| `sst_anom_naive3` | The earlier construction (mean of naive anomalies at 46029, 46041, 46211), kept for comparison only |
| `index_vintage` | Which BEUTI/CUTI/PDO vintage built this table: `cached` (default) or `current` (`run_all.R --vintage=current`) |
| `oisst_*`, `mur_*`, `ndbc_met_*`, `columbia_lower_*`, `upwelling_*`, `pdo_ncei`, `pdo_psl` | External products joined from `02_data/Environmental Data/external/<stem>_monthly.csv` (satellite SST, buoy winds and waves, lower-Columbia gauges, current index vintages); see that folder's README |

## `sst_station_parameters.csv`

One row per station in the homogenised SST series: record length, gain (fixed at 1 in the pipeline fit) and error SD used as the precision weight.

## `cohort_table.csv`

One row per beach × year class Y (1988–2024). Year class Y is spawned and settles in summer Y.

| Column | Meaning |
|---|---|
| `beuti_larval` | BEUTI May–Aug of Y (46°N for Long Beach, 47°N otherwise) |
| `sst_larval` | `sst_anom` May–Sep of Y |
| `pdo_larval` | PDO May–Sep of Y |
| `q_freshet` | Columbia discharge Apr–Jun of Y |
| `cuti_winter` | CUTI Nov Y – Feb Y+1 (negative = downwelling) |
| `pre_next`, `log_pre_next`, `doy_next`, `p_lt30_next` | Pre-recruits counted at survey Y+1 and that survey's date and settler share |
| `rec_next2`, `log_rec_next2` | Recruits at survey Y+2 |
| `spawners`, `log_spawners` | Recruits at survey Y (spawning stock for year class Y) |

The five predictors were fixed before any correlation with clam data was examined; rationale in `docs/methodology-review.md` §5.2. Window means require ≥75% of months to be present.
